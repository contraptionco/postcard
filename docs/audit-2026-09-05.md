## Other concrete findings encountered

- Public subscription create calls `.strip` on potentially nil input and dereferences `@account` without an explicit missing-account response; hostile/malformed requests can raise 500 before a useful validation response.
- `Account#host` assumes every nonempty domain collection has a primary domain; only redirect domains can cause nil dereference.
- Custom-domain regex only permits a 2–5-letter TLD (`domain.rb:14`), rejecting legitimate longer domain suffixes before onboarding completes. Validate full DNS label rules rather than only changing the email regex.
- Page edits call `generate_icon` regardless of photo change; unnecessary decoding/download happens even for bio/name changes.
- Registered newsletter checkbox and OAuth flow need a consent-consistency audit; One Tap would add a third inconsistent signup implementation.
- Existing Markdown/llms.txt functionality is only mentioned in HTML comments; RSS is autodiscovery-only. Visible export/feed links are a low-risk feature idea worth exposing.
